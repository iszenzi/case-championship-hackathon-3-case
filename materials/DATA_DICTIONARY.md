# Входы и единицы

Все поля данных определены в src/economy.js. Полные значения пяти опорных сценариев лежат в data/scenarios.json.

| Поля | Единицы и смысл |
|---|---|
| n, wait, setup, capacity | Платформы; оставшиеся сутки ожидания; сутки подготовки; доступные вагонов/сутки |
| storageDays, seaDelta | Сутки хранения альтернативы; разница следующего плеча до того же получателя |
| portTariff, portAvoid | ₽/C40 выручки Ванино; % реально избегаемых своих расходов |
| altPrice, storePrice | ₽/C40 перевалки; ₽/C40/сутки хранения |
| movePrice, moveFixed | ₽/платформу и ₽/партию оплаты перевода РЖД |
| moveCost, altCost, storeCost | Дополнительные расходы исполнителей за всю партию с учётом вытесненной маржи |
| rzdDaySaving, rzdMargin | ₽/расчётные сокращённые вагоно-сутки; новая маржа РЖД за партию |
| projectCost, penalty | Внедрение за партию; причинно предотвращаемые пени РЖД в пользу Ванино |
| privateRate, operatorSaving | Частная плата порта оператору ₽/вагон/сутки; реальный эффект оператора за партию |
| cargoValue, capitalRate, cargoExtra | Стоимость всей партии ₽; индивидуальная годовая ставка %; прочие расходы клиента ₽ |
| otherFloor, rzdFloor | Минимальные эффекты партнёрам и РЖД за партию ₽ |
| pool | 1: общий фонд с возвратами маржи; 0: РЖД только покрывает недостачу |

Денежные результаты знаковые: плюс — улучшение относительно ожидания, минус — ухудшение. Пени и компенсации должны иметь встречную запись. Недостающие фактические величины в контрольном сценарии заменены явно описанными условиями сравнения, а не объявлены измеренными нулями.
