# Повторение расчёта

Python 3.10+ и Node.js 18+ в PATH. Основной расчёт использует стандартную библиотеку Python, внешние API и ключи не нужны.

Из корня репозитория:

```bash
python model/scripts/reproduce.py
python -m unittest discover -s model/tests -v
python model/scripts/check_repository.py
```

Первая команда собирает demo/index.html, восстанавливает портовые примеры точной дробной арифметикой, сверяет независимые Python/JavaScript-реализации на 255 наборах и записывает результаты в model/results. Входы не меняются, интернет не используется. В GitHub Actions проверяются те же команды и отсутствие отличий заново созданных файлов.

Основные файлы:

- model/src/economy.js — расчёт шести сторон и компенсаций;
- model/src/dashboard.js — интерфейс;
- model/data/scenarios.json — полные входы опорных сценариев;
- model/results/scenarios.json — входы и результаты тех же сценариев;
- model/results/stakeholders.csv — таблица результатов сторон;
- model/results/verification.json — итог независимой проверки 255 наборов;
- model/results/port_scenarios.json — точные портовые примеры, параметры и границы цены;
- model/tests/test_economics.py — проверки отрицательных случаев, баланса и времени.

При изменении числа платформ пересчитайте себестоимости исполнителей: они заданы на всю партию. Изменения через HTML можно экспортировать в JSON, но они не переписывают исходные файлы репозитория.

Время подготовки определено до начала обработки первого вагона. Завершение платформы i: setup+(i+1)/capacity при нумерации с нуля. Остаточная плата считается отдельно по каждой платформе.

Необязательная проверка интерфейса: `node model/scripts/check_browser.cjs`. Для неё отдельно нужны Playwright и Edge. Скрипт сохраняет снимок в игнорируемую local/ и результат в model/results/browser_checks.json. Нестандартный путь к пакету задаётся PLAYWRIGHT_MODULE_PATH, канал браузера — BROWSER_CHANNEL. Основная численная проверка от этого не зависит.

Фактическая доступность терминала, судна и достоверность коммерческих входов программными тестами не подтверждаются.
