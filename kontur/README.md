# Контур 4.1 — расчёт по Excel

Все 69 строк и 168 альтернатив перенесены из «Выгода_РЖД_69_сценариев.xlsx». Выгода = предполагаемая предотвращённая выплата − смета перевода. Отдельно показаны остаточная выплата, баланс B и денежный результат после выплат и затрат. Первые значения: 2 264 209 ₽, 2 030 000 ₽, 0 ₽, 62 121 862,54 ₽. Это сценарная модель с допущениями исходного Excel, не достигнутая экономия. Суммы разных лет не экстраполируются в годовой эффект. Исторические судебные факты пяти досье сохранены отдельно.

Одна кнопка открывает заполненную карточку и вызывает МАИ для объяснения; итоговый выбор и математика воспроизводят Excel, не случайный ответ модели. Параметры за кнопкой: партия/риск, ж/д операции, перевалка, хранение, море, маршруты. Фиксация сохраняет решение в сценарии. Старые записи с иной методикой остаются в БД и не подмешиваются в журнал новой версии.

Исключено по основаниям: 2 868 854,20 ₽; дополнительно снижено судом: 28 829 520,29 ₽. Разность 31 698 374,49 ₽ — исторический судебный результат, не сбережения нашего ИИ и не годовая выгода. По видимым номерам явных пересечений между группами не найдено, но скрытые/неполные накладные не позволяют гарантировать отсутствие повторов. Госпошлина отдельно.
ИИ получает факты и вопрос, без денежного итога и контрольного ответа. Ссылки — ID фактов, текст подставляет сервер; модель не копирует цитаты. Старый court API также переведён на source_units/IDs.
Контрольные карточки подготовлены командой. Initial-прогон 3/5 строгих совпадений; после уточнения вопросов, определений и документальных фактов — 4/5. Референсные action/issue ID не менялись по ответам модели. Это настройка на тех же пяти случаях, не независимый тест. Во всех пяти ответах модель не разрешала неподтверждённый перевод. Экономия труда, дополнительная прибыль ИИ и предотвращение конкретного иска пока не измерены. Полные протоколы research/verified_five_e230, не в поставляемом ZIP.
