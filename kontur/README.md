# Демо сценариев перевозок

Python-приложение сравнивает 168 альтернатив в 69 сценариях. Формулы и суммы перенесены из командного Excel; ИИ МАИ объясняет условия и рекомендацию. Это сценарный расчёт, а не измеренная экономия РЖД. Доступность терминалов и предотвращение выплат заданы условиями примеров. Подключения к оперативным системам РЖД нет.

## Запуск

Нужны Python 3.10+ и браузер. Обязательных сторонних Python-пакетов нет.

```bash
cd kontur
python -X utf8 server.py --port 8768
```

Откройте `http://127.0.0.1:8768/`. «Открыть сценарий» показывает условия и альтернативы без суммы и выбора. «Сделать расчёт» запускает разбор ИИ: результат появляется прямо на карточке, а внутри доступны финансовая раскладка, объяснения и зелёное выделение выбранного маршрута. Повторное открытие в той же сессии использует готовый результат. После перезагрузки страницы карточки снова начинаются без расчёта; серверные записи доступны в разделе «Решения».

Для ИИ задайте собственный ключ МАИ в `.env` по образцу [.env.example](.env.example). Ключ в браузер не передаётся. Без ключа условия доступны, а попытка расчёта сообщает об отсутствии настройки. Проверка TLS включена.

Чтобы хранить конфигурацию и SQLite отдельно от исходников:

```bash
python -X utf8 server.py --port 8768 --data-root /absolute/path/to/private-runtime
```

В этом случае `.env` должен находиться в указанном каталоге. Рабочие базы, ключи и приватные архивы не входят в Git. Для локального запуска используйте команду Python выше: Windows-ярлыки могут подключаться к уже настроенной командной ВМ.

## Проверка

Из каталога `kontur`:

```bash
python -X utf8 -m unittest -q test_app test_court test_judicial test_scenario_engine test_operator_decisions
node --check web/jury.js
node tests/check_ui.cjs
python -X utf8 build_release.py --skip-checks
```

Node.js нужен только для проверок разработки. Последняя команда собирает исходники в `kontur/dist/`, исключая ключи и рабочие данные. UI-проверка охватывает 69 сценариев и 168 альтернатив, скрытие результатов до запуска, отображение после ответа, переход к подробностям и ошибку API. Эти проверки не вызывают внешнюю модель.

`test_scenario_engine.py` сверяет финансовые результаты с сохранёнными значениями Excel. Остальные Python-тесты проверяют сервер, хранение, ограничения и прежние исследовательские API. В текущем меню только «Сценарии» и «Решения».

## Ограничения

Итоговый выбор и деньги определяет код по профилю Excel; языковая модель объясняет условия. Причинный денежный эффект самого ИИ не измерен. Исторические судебные факты и авторские альтернативы имеют разный статус доказательности. [Описание проверок](VALIDATION.md) и [выбор модели](MODEL_SELECTION.md) относятся к исходной поставке; некоторые описанные там экраны были изменены позднее.

## Решение оператора

После расчёта выберите вариант 1, 2, 3 или сохранение исходного маршрута и нажмите «Зафиксировать решение». Автоматического выбора за оператора нет. Рекомендация ИИ сохраняется отдельно от решения человека. Для варианта, не подходящего по условиям, показана причина; его фиксация в демо не отправляет распоряжение о перевозке. В журнале «Решения» видны только зафиксированные записи и эффект выбранного оператором варианта. Повторная фиксация и изменение закрытого расчёта запрещены; для нового решения откройте новый сценарий.

После фиксации главный блок, финансовая раскладка и карточка в каталоге показывают выбранный оператором маршрут. Другие варианты больше не подсвечиваются как рекомендации. Зафиксированное решение сохраняется после перезагрузки и повторного открытия. Кнопка «Очистить решение» в журнале снимает фиксацию, возвращает сценарий к новому расчёту и записывает событие очистки в аудит. Если у сценария есть несколько старых записей, очистка последней не восстанавливает автоматически более старый выбор.
