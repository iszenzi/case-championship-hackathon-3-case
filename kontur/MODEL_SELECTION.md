# Выбор модели МАИ · 13 ноября 2026

**Выбрана qwen3.6-35b-a3b** как рабочая модель для извлечения фактов и ответов по источникам.

С предоставленным ключом API МАИ действительно выполнены 36 модельных запросов: первичная проверка четырёх моделей на четырёх сообщениях и одном вопросе по источнику, затем два финалиста на восьми дополнительных сообщениях. Параллельность — два запроса, temperature=0, лимит ответа 1 800 токенов. Проверялась применяемая в продукте связка модели, проверки цитат и нормализации полей.

| Модель | Первый набор: точные разборы | Медиана первого набора | Дополнительный набор | Медиана дополнительного |
|---|---:|---:|---:|---:|
| **qwen3.6-35b-a3b** | 4/4 | 2,35 с | **7/8** | **3,10 с** |
| qwen3.8-flash-next | 4/4 | 2,99 с | 7/8 | 3,95 с |
| Qwen3.5-122B-A10B | 4/4 | 14,28 с | Не проверялась | — |
| deepseek-v4.1-flash | 4/4 | 40,33 с | Не проверялась | — |

Все четыре модели вернули ответ по документу с допустимым идентификатором источника. Это проверка формата и ссылок, а не независимая экспертиза каждого утверждения.

У обоих финалистов одна ошибка: из сообщения «Груз негде разместить, склад заполнен. Приём остановлен, длительность не установлена» они вывели локальный охват, хотя из текста он не установлен. Проверка специалистом остаётся обязательной. В сумме у выбранной модели 11 точных разборов из 12 учебных сообщений; ошибка не скрыта и не исправлялась задним числом в протоколе.

Условия выбора: сначала корректность критических полей, затем корректность ссылок, число ошибок API и медианное время. Большее число параметров и слово Flash в названии сами по себе не определяют выбор.

Набор небольшой, синтетический и размечен автором, без независимого эксперта. Задержка API зависела от очереди: отдельные запросы занимали существенно дольше медианы. Это предварительный выбор для этого сценария, а не универсальный рейтинг моделей и не доказательство экономии рабочего времени. Цена API МАИ не выводилась из названия модели; коммерческие ставки калькулятора остаются допущениями.

Воспроизводимый код — `research/mai_model_selection_e228.py` рабочей папки проекта; полные локальные ответы и времена — `product/dils-copilot/qa/mai-selection.json`. Ключи в этих файлах отсутствуют.

## Версия 2.0

Модель закреплена: qwen3.6-35b-a3b, только API МАИ. Изменение через веб-интерфейс отключено. В новой судебной лаборатории промпт отдельно различает занятость терминала, подготовку груза, ремонт вагонов и завершённый денежный спор. Небольшой прежний тест не является оценкой точности на всех 69 новых сценариях. В первоначальном новом разборе №1 модель ошиблась с категорией; интерфейс показывает расхождение и оставляет исходную категорию для проверки человеком.
