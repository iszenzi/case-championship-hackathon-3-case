# Цепочка API МАИ

Публичные сертификаты Russian Trusted Root CA и Russian Trusted Sub CA загружены с официального CDN Госуслуг по HTTPS с обычной проверкой сертификата источника. URL и SHA256 приведены в SOURCES.json.

`llm.tls_context()` добавляет их только в контекст конкретных соединений к `api-ai.mai.ru`. Остальные адреса используют обычные системные корни. Проверка имени хоста и сертификата не отключается, системные хранилища не изменяются.

Это публичные сертификаты удостоверяющего центра. Секретного ключевого материала здесь нет.
