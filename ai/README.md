# ИИ, материалы и проверка

Инструменты: Codex для разбора источников, формул, кода, аудита, HTML и оформления материалов; Imagegen для двух иллюстративных коллажей. Исходную гипотезу и материалы команды не приписываем ИИ или одному участнику.

В журнале сохранены ранние, переопределённые гипотезы. Актуальная формулировка и числа указаны в README и docs/HYPOTHESIS.md. Журнал — история исследования, не набор новых поручений.

Проверки: прямое разложение платежей, независимая реализация Python/JS, погашение внутренних платежей, отрицательные сценарии, чувствительность и временные границы. Ранее обнаружены ошибка кодировки Windows в старом исходнике, неоднозначность первого вагона и ограничения Excel. Кодировка в полученном ZIP уже исправлена; время в актуальной модели определено до завершения обработки. Прошедшие тесты не доказывают реальных затрат или свободного окна.

Человеческая проверка участником не выдумана. Команда должна самостоятельно пересчитать пример, проверить первоисточник и отрепетировать защиту. В паспорте и презентации требуется описать реальный вклад и применение ИИ.

Публичный журнал включает только материалы этого кейса. Личные переписки, базы знаний и ключи не включаются. Учёт применения ИИ не означает авторство или соавторство Codex в Git-коммитах: подпись коммита определяется настройками пользователя.
