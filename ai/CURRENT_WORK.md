# Последние задачи и решения

Это содержательный журнал запросов и проверок, не дословный экспорт личной переписки.

| Событие | Запрос / решение команды | Выполненная работа и вывод |
|---|---|---|
| E200–E201 | Проверить предложенную командой схему Ванино | Арифметика воспроизведена, положительный эффект зависит от допущений |
| E205–E206 | Разделить интересы порта и РЖД, проверить судебные пени | Пени и плата за нахождение разделены, предотвращаемая сумма не доказана |
| E209 | Подготовить расчётный комплект на имеющихся данных | Историческая клиентская постановка, в актуальную версию не переносится автоматически |
| E210 | Показать экономику РЖД и условия согласия всех сторон | Модель шести сторон, два соглашения, баланс платежей, 255 проверенных наборов |
| E211–E213 | Подготовить презентацию и исправить анимацию объектов | 8 слайдов, 63 эффекта распознаны WPS; Microsoft PowerPoint playback не заявлен |
| E212 | Сохранить итоговую гипотезу дословно | Формулировка относится к расходам Ванино, расширенный расчёт акцентирует РЖД |
| E214 | Проверить новый ZIP сокомандника | 44 хеша, 11 CSV, 777 наборов и 111 проверок; портовая экономика, а не прибыль РЖД |
| E215 | Оформить репозиторий по требованиям А3 без паспорта | Подготовлены структура, актуальная гипотеза, код/данные/результаты, источники, презентация, roadmap, журнал и проверки; Git-подпись пользователя |

Результат сборки и проверок фиксируется в results/repository_checks.json. Публикация кода не равна отправке заявки через форму организаторов и не доказывает допуск в финал.
