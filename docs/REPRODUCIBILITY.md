# Повторение расчёта

Python 3.10+ и Node.js 18+ в PATH. Модель работает на стандартной библиотеке Python; Node нужен для проверки JavaScript. Внешние API и ключи не используются.

```bash
python scripts/reproduce.py
python -m unittest discover -s tests -v
```

Первая команда собирает автономный HTML из шаблона и двух JS-файлов, восстанавливает точной дробной арифметикой портовые примеры, сверяет Python с JavaScript на 255 наборах параметров и записывает результаты. Она не меняет исходные входы и не обращается в интернет. Контрольные файлы в results можно сравнить с Git, например `git diff -- results app/index.html`.

Отдельные команды:

```bash
python scripts/build_dashboard.py
python scripts/port_examples.py
python scripts/audit_python_js.py
node scripts/export_scenarios.cjs
```

Данные готовых сценариев находятся в data/scenarios.json. Веб-интерфейс позволяет вводить дополнительные варианты и экспортировать их в JSON; интерактивные изменения не сохраняются в исходные файлы репозитория. Себестоимости перевода, терминала и склада заданы за партию: при изменении N их нужно пересчитать отдельно.

Для проверки только исторического архива:

```bash
python archive/teammate/model/run_model.py
python archive/teammate/model/verify_model.py
python archive/teammate/verify_dashboard.py
```

Эти команды используют старую конвенцию времени первого вагона, записывают данные только в archive/teammate/results и не определяют актуальные числа README. Нельзя смешивать старые 10 910 ₽ остаточной платы с новыми 11 275 ₽.

Browser QA последних исходных версий выполнялась в Edge при 1440×1000 и 390×844. Для опубликованной версии отдельно проверяются отображение итоговой гипотезы, переключение сценариев, JSON и неверный ввод. CI проверяет математику и воспроизводимость, но не подтверждает реальные операции.

Необязательная проверка интерфейса: `node scripts/check_browser.cjs`. Для неё отдельно требуется пакет Playwright и установленный Edge. В основной численный запуск эта зависимость не входит. Скрипт сохраняет снимок в игнорируемую папку `local/` и краткий результат в `results/browser_checks.json`. При нестандартном расположении пакета можно задать `PLAYWRIGHT_MODULE_PATH`, при другом браузере — `BROWSER_CHANNEL`.
